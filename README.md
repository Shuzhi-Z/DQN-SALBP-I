# DQN-SALBP-I

**A Deep Q-Network Based on Reinforcement Learning for Solving the Assembly Line Balancing Problem**

This repository presents a DQN-based approach for solving the Simple Assembly Line Balancing Problem Type-I (SALBP-I), with performance comparisons against Q-learning and DPGA.

**Benchmark Data:**  
The benchmark instances are obtained from the Assembly Line Balancing repository:  
https://assembly-line-balancing.de/salbp

The manuscript and source code will be made publicly available upon acceptance of the paper.
